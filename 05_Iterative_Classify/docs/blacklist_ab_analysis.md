> （55.3% vs run1 54.7%，+0.6pp）；本文 armB 55.0% 来自旧嵌入副本
> （脚本漂移 0.3pp，机制结论不受影响）。

## 二、机制层：管家基因为什么能进 top-50

**1. "稳定表达"的精确含义被误用了。**
管家基因的稳定 = **群内方差小**（qPCR 内参逻辑），不是**群间无差异**。
而统计检验的灵敏度 = 群间差 / 群内方差——群内方差越小，同样大小的群间差
p 值越极端。稳定基因恰恰是最敏感的探测器：它进 top-50 不需要大的生物学
失调，只需要微小的组间偏移。

**2. 三层信号叠加，都不是"管家基因失调"：**

| 信号 | 机制 |
|------|------|
| 总转录量差异（主导） | 管家基因 = 每个细胞都表达的高丰度基因 = 总 UMI 的天然标尺。恶性簇细胞更大/更活跃 → raw counts 同向抬高；pseudobulk 检验吃 raw counts，读的就是这个 |
| 应激/死亡 | 黑名单 12 个中 5 个是热休克蛋白（HSP90AA1/AB1/HSPA1A/1B/HSPA8）——本质是应激诱导基因，解离 37°C + FACS 的应激信号被读成组间差异 |
| 统计功效 | 高检测率 + 低方差 → p 值碾压 |

**3. 方向相反是最有力的定位证据。**
论文 Table S2 里 TMSB4X/EEF1A1 在非恶性方向，我们的数据里在恶性方向。
同一批管家基因、两个数据集、方向相反——说明它们读的从来不是自己，
是**比较对象的属性**（哪一组的细胞总转录更高/更应激）。谁总转录高，
管家基因就站在谁那边。

**4. 自指回路放大（幅度打折的理由）。**
iter2 起签名已含管家基因 → 高管家基因细胞被评进恶性簇 → 下一轮 DEG
恶性簇管家基因更高 → 排名更靠前。初始组间差异真实存在（iter1 即 7 个
命中垫底），但幅度被这个正反馈放大。管家基因是迭代里唯一有自我强化
物理基础的基因类（身份基因受谱系约束，管家基因只受总转录量约束）。

## 三、效应小的原因：信息冗余

管家基因与主导 IM 轴**协变**（恶性簇既 IM 化又总 UMI 高，两信号同向）——
它们携带的信息被另外 44 个签名基因覆盖。黑名单拔掉 6 个（等权评分下
6/50 分量），补位基因同为恶性方向 → 签名方向不变，切点微移。
效应小不是因为信号弱，是因为信号冗余。

## 四、判别力边界（为什么不能反过来用）

"恶性簇管家基因高"≠"管家基因高的是恶性"。UMI 膨胀的生物学来源是
三元混合物：

1. **增殖**：G2M 期体积翻倍 + 核糖体上调——胃上皮 2-4 天更新，正常
   增殖细胞大量存在；增殖轴与恶性身份解耦（MSDA PCA 正交性：
   mean |r| = 0.061）
2. **大细胞类型**：Parietal（酸泵）/ Chief（酶原颗粒）天然巨型；
   MSDA 实测高 UMI 尾部 ~86% 是真大单细胞
3. **恶性特异转录扩张**：真信号，但只主导**极端尾部**

| 区间 | 判别力 |
|------|------|
| 15k–30k UMI | tumor 88.9 vs control 12.8 /100k——富集 ~7× 但绝对罕见，不是判别器 |
| >100k UMI | tumor 45 vs control 0——方向成立；Kim 金突变上皮证实深液滴藏真恶性 |

## 五、结论

定位 = **敏感性分析注脚（非主要证据）**：论文迭代环节无黑名单声明
（§1.5 纯 top-50）+ Table S2 有管家基因 → 本实验定量"加黑名单会怎样"
→ 几乎不变（端到端量化以星形 run4 为准：55.3% vs 54.7%，+0.6pp）。
一个被证实无害的瑕疵，比未检验的疑点有价值。
边界：黑名单轴到此为止（六轴中效应最小，不同管家列表扫描边际收益为零）。
